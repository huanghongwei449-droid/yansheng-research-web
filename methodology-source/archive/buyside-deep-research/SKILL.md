# 买方深度研究（Buy-Side Deep Research）· v6

> **版本说明**：本 skill 为 v6 通用公司研究文章版。定位为围绕公司主问题融合业务、行业、财务、估值等多维度信息，形成有主线、有判断、有买方价值的深度研究文章，而非资料堆叠或研报摘要。

## 一、定位：先判断"这家公司当前真正的问题是什么"

这是一篇买方深度研究，不是公司百科，不是行业穿透，不是持仓诊断，不是券商研报摘要，也不是把业务表、财务表、估值表机械拼接。

**本文的主角是公司本身。** 你要回答的不是"这个行业怎么样"，而是：

- 这家公司为什么现在值得研究
- 市场当前对它的核心分歧是什么
- 它到底靠什么赚钱
- 它的利润质量是否真实
- 它的估值隐含了什么预期
- 如果核心变量兑现，它应该怎么被定价
- 如果核心变量不兑现，错在哪里、风险在哪里
- 未来应该看什么数据验证或证伪

**注意**：不要预设这家公司一定是"重估""反转""AI赋能""国产替代""困境反转"或"低估值修复"。必须先根据资料判断它真正属于哪一类研究问题，再组织文章。

### 12 种研究类型

| 类型 | 核心问题 |
|------|---------|
| **成长兑现型** | 市场相信公司未来增长，关键是收入和利润能否兑现 |
| **估值切换型** | 业务结构或商业模式变化，市场可能从旧估值框架切到新框架 |
| **困境反转型** | 过去业绩受压，关键是压制因素是否消失、利润是否恢复 |
| **周期反转型** | 公司处在价格、库存、产能、资本开支周期变化中 |
| **资产价值型** | 现金、土地、投资资产、牌照、资源、股权等资产价值可能被低估 |
| **现金流/分红型** | 成长有限，但现金流、分红、回购、资本配置决定价值 |
| **事件催化型** | 并购、重组、订单、政策、退出、涨价、招标等改变市场预期 |
| **主题验证型** | 被放进某个热门主题，需要判断是真受益还是概念映射 |
| **商业模式升级型** | 从硬件到软件、项目制到订阅、低毛利到高毛利、一次性到持续 |
| **经营杠杆型** | 收入增长、毛利率改善或费用率下降可能带来利润弹性 |
| **财务修复型** | 扣非利润、现金流、应收、存货、商誉、减值、债务等是核心 |
| **治理/筹码压制型** | 减持、解禁、定增、股权激励、管理层变化、资本配置影响定价 |

实际写作时，**根据公司真实情况选择最合适的主线，不要机械套用任何一种模板。**

## 二、文章目标

这篇文章最终要让读者看懂：

- 这家公司到底是什么生意
- 客户是谁，客户为什么付钱
- 收入和利润从哪里来
- 最赚钱、最值钱、最拖累的业务分别是什么
- 它过去为什么被市场这样定价
- 现在市场的分歧是什么
- 核心变量是什么
- 这些变量如何传导到收入、毛利率、费用率、利润、现金流和估值
- 当前市值隐含了什么预期
- 如果看多，买的到底是什么
- 如果看错，错在哪里
- 下一次财报或事件应该看什么

**目标读者**：有金融和投资基础，但可能没有该公司所在行业经验的人。

读者看完后应当能够用自己的话讲清楚：公司怎么赚钱、为什么现在有分歧、估值到底贵不贵、市场可能低估/高估了什么、接下来什么数据能验证或证伪。

## 三、最高优先级：先抓"公司主问题"

正式写作前，先在内部确定本文的公司主问题。**每一章都必须服务于主问题。** 如果某个信息不能解释收入、利润、现金流、估值、赔率或风险，就不要展开。

公司主问题可能是：

- 它是真成长还是短期主题
- 它是便宜，还是利润质量差所以便宜
- 它是低估值现金牛，还是价值陷阱
- 它是困境反转，还是基本面继续恶化
- 它是行业变化的核心受益者，还是概念相关
- 它的利润增长来自主业，还是投资收益、补贴、汇兑、会计因素
- 它的高估值是否能被未来利润消化
- 它的现金到底能不能自由支配
- 它和海外对标到底哪里相同，哪里不同
- 它当前市值到底在赌什么

## 四、工作流程

### 阶段 0：确认公司身份

用 `search(source="web")` 搜索公司基本信息（股票代码、主营业务、营收结构、当前市值），在用户知识库中搜索相关研报。识别公司的核心定价变量（并购？转型？周期？注入？）。

### 阶段 1：并行检索（5 个研究子代理）

**必须在同一条消息中并行发起 5 个 `subagent_spawn(type="research")`**。每个子代理的 prompt 须包含阶段 0 获取的公司基本信息。

| 子代理 | 研究维度 | 搜索关键词示例 |
|--------|---------|--------------|
| **子代理 1：财务深度** | 杜邦分解、现金流、负债、商誉、研发资本化、业务结构变化 | `[公司名] ROE 杜邦 近五年 年报 财务分析` |
| **子代理 2：产业链+竞争格局** | 产业链全景、瓶颈环节、竞争格局、国产化率、壁垒 | `[行业名] 产业链 竞争格局 市场份额 国产化率` |
| **子代理 3：可比公司估值对标** | 3-6家可比公司PE/PB/PS/ROE，SOTP分部估值，卖方一致预期 | `[公司名] 可比公司 估值 PE PB 目标价 评级` |
| **子代理 4：筹码面+催化剂+资本运作** | 两融、北向、解禁、质押、股东结构、定增/股权激励/减持全景 | `[公司名] 融资融券 北向资金 解禁 质押 股东 定增 股权激励` |
| **子代理 5：业务上下游产业链细节** | 供应商、客户、新业务来源（自建/收购/合同）、各业务毛利率 | `[公司名] [各业务名] 供应商 客户 毛利率 收购 合同` |

**子代理规则**：所有子代理 `type="research"`（只读）。prompt 中须包含公司全称、股票代码、阶段 0 确认的核心定价变量、最近一期财报时间。每个子代理返回结构化的研究结果（按维度分段，带数据来源标注）。阶段 1 不输出给用户。

### 阶段 2：逻辑链融合撰写

收集齐 5 个子代理结果后，按以下逻辑链组织报告：

```
公司是谁 → 做了什么（每件事交代来源） → 值多少钱（逐项拆开）
→ 差额在赌什么 → 风险 → 结论（二元化）
```

### 阶段 3：补充迭代

阶段 2 输出后，按**核心写作原则**逐条对照检查。发现缺口时使用 `search`/`fetch`/额外 `subagent_spawn` 补查，更新报告。

### 阶段 4：交付

将完整报告写入 `/sandbox/workspace/outputs/{公司名}_深度研究报告.md`。如需转 PDF，用 Python（markdown + weasyprint）转换。

## 五、核心写作原则

### 原则 1：文章优先，表格克制

报告必须是一篇完整的买方研究文章。表格只能用于压缩数据（核心财务数据、业务结构摘要、可比公司摘要、情景假设、验证指标）。**任何表格之后必须有文字判断，不能让读者自己看表找结论。**

### 原则 2：不准写公司百科

不要机械介绍公司历史、创始人、产品线。必须回答：公司最初靠什么起家、现在主要收入/利润来自哪里、哪块业务决定收入规模/利润质量/估值弹性、哪块业务只是补充/拖累/概念映射、核心能力是什么（自研/渠道/牌照/资源/客户关系/产能/算法/数据/品牌/供应链/管理效率）。

### 原则 3：每个核心业务都要讲清"赚钱机制"

对每块核心业务，必须讲清楚：卖什么、谁买、客户为什么必须买、客户预算来自哪里、怎么收费、收入增长来源（量/价/客户数/ARPU/渗透率/产品结构/并表/一次性）、毛利率为什么高或低、成本主要是什么、费用是否刚性、什么指标能验证这块业务变好、什么指标说明只是故事。

### 原则 4：行业逻辑必须落到公司变量

禁止写"行业景气，公司受益"。必须写清楚：行业变化改变了哪些客户的采购行为→公司处在哪个环节→公司为什么能接到订单→订单如何确认收入→收入是否提高毛利率→毛利是否被费用吞掉→财报上最先看到哪个指标→如果逻辑错了在哪个指标上暴露。

### 原则 5：财务分析必须讲成"利润发动机"

财务部分不是列数据，而是解释利润如何被制造出来。必须拆清楚收入来源、成本结构、毛利率变化、各项费用、经营利润、扣非利润、归母净利润、非经常性损益、经营现金流、资产负债表风险、资本开支和折旧、应收/存货/合同负债、商誉/减值、现金和债务。

尤其要区分：**表观利润 vs 真实经营利润、归母利润 vs 扣非利润、利润增长 vs 现金流改善、主业增长 vs 非经常性收益、一次性改善 vs 可持续改善。**

### 原则 6：可比公司必须先解释，再比较

每个核心可比对象必须先解释：它是什么类型的公司、为什么可比、哪里不可比、商业模式/客户结构/毛利率/费用率/收入确认/成长阶段是否一致、市场给它的估值锚是什么。**禁止因为名字像、概念像、海外龙头估值高就直接套估值。**

### 原则 7：估值必须反推市场预期

不能只写 PE/PB/PS/EV/EBITDA 或券商目标价。必须从当前市值反推：当前市值对应多少收入/利润/现金流→剔除现金和投资资产后的主业价值→当前估值隐含未来几年利润到多少→要达到这个利润需要什么收入增速/毛利率/费用率/净利率假设→当前价格已经相信了什么/还没验证什么。

### 原则 8：必须区分事实、推理和假设

- **已验证事实**：公告、财报、订单、政策、行业数据、已经发生的事件
- **合理推理**：基于行业变化、客户行为、财务结构、商业模式变化得出的判断
- **尚未验证假设**：未来订单、未来利润、未来估值切换、未来份额提升、未来成本下降

不能把假设写成事实，不能把券商测算写成公司已披露数据，不能把调研纪要或社区传闻写成强证据，不能用海外对标替代公司自身验证。

### 原则 9：必须加入反向审判

买方深研不能只写看多逻辑。必须主动审判：看多逻辑最容易错在哪里、市场是否已经提前反映、收入/毛利率可能不兑现、费用可能吞掉毛利改善、现金流不支持利润、应收/存货/商誉/减值风险、行业变化可能绕开公司、可比公司不能直接对标、治理/减持/资本配置压制估值、估值已透支未来。**没有反向审判的文章就是单边推票，不是买方研究。**

### 原则 10：结论必须有买方态度

不能写"建议关注""长期看好但短期有风险"这种空话。必须回答：买它到底买的是什么、不买它的核心理由是什么、当前赔率和胜率在哪里、下一阶段最关键的验证点、什么数据出现说明判断增强/必须承认判断错了。

## 六、通用分析模块

根据公司实际情况选择使用，不必机械全部写。

### 模块一：公司基本盘
公司做什么、客户是谁、产品或服务是什么、怎么收费、收入结构、利润结构、核心资产、核心能力、业务来源（自研/收购/资源/渠道/牌照/客户关系/周期红利）。

### 模块二：业务分层
哪块业务贡献收入/利润/现金流/估值想象、哪块业务拖累利润/只是概念映射、各业务之间是否有客户/渠道/技术/成本协同。

### 模块三：行业到公司的传导
行业变量→影响哪些客户→客户采购什么→公司卖什么→公司为什么能拿到订单→订单如何确认收入→收入如何影响毛利率→毛利如何变成利润→哪些财务指标最先验证。

### 模块四：财务质量和利润发动机
利润来自主业还是非主业、收入增长和利润增长是否匹配、毛利率变化是否可持续、费用率是否有下降空间、扣非利润是否改善、经营现金流是否跟得上净利润、应收/存货是否异常、合同负债是否支持订单、商誉和减值风险、资本开支和折旧压力、现金是否真正可自由使用。

### 模块五：资产和资本配置
现金和类现金资产有多少、是否可自由支配、投资资产是否应单独估值、分红和回购是否稳定、资本配置是否有效、资产价值能否转化为股东回报。

### 模块六：可比公司和资产属性
它到底应该和谁比、为什么比、哪里不能比。成长股/价值股/周期股/平台公司/现金牛/困境反转/事件驱动/主题成长/资源品/制造龙头/软件SaaS/硬件设备商/项目制公司。

### 模块七：市值隐含预期（必须使用）
当前市值在定价什么、当前估值隐含未来收入和利润到什么水平、当前价格已经相信了什么/还没验证什么、预期差在哪里。

### 模块八：情景推演
不要机械写乐观/中性/悲观。情景必须围绕核心变量，每个情景讲清楚：哪个变量变化、为什么影响收入/毛利率/费用率/利润/估值倍数、对应风险和空间。

### 模块九：治理、筹码和事件因素
事件本身是什么、影响基本面/现金流/估值/筹码还是市场信心、是短期压制还是长期伤害、是否改变原始投资逻辑、什么时候解除。

### 模块十：验证和证伪指标（必须使用）
列出未来需要观察的公司指标：收入增速、订单、合同负债、毛利率、费用率、扣非利润、经营现金流、应收账款、存货、客户续约率、新业务收入占比、产能利用率、资本开支、减持/回购/分红、行业价格、竞争对手动作、关键客户采购、政策执行进度。**具体指标必须根据当前公司调整。**

## 七、建议文章结构

不要机械使用固定标题，根据公司真实问题自行组织。但无论怎么组织，文章必须包含以下内容：

1. 当前为什么要研究这家公司（提出公司主问题，不是列数据）
2. 公司到底靠什么赚钱（业务、客户、收费方式、收入和利润来源）
3. 市场过去为什么这样看它（资产属性、估值框架、市场偏见）
4. 现在的核心变量是什么（变化来自行业/公司/财务/治理/事件/估值框架）
5. 变化如何进入收入、毛利率、费用率和利润（公司层面的传导链，不跳结论）
6. 财务质量：表观利润和真实经营利润是否一致
7. 和谁比，为什么比（解释可比公司和资产属性）
8. 当前市值隐含了什么预期（反推收入、利润、利润率、估值倍数）
9. 反向审判：看多逻辑可能在哪里错
10. 情景推演：核心变量兑现与不兑现
11. 验证指标：接下来哪些数据最关键
12. 买方结论：买的是什么，错的风险是什么
