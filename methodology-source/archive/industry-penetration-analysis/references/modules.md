# 分析模块详细指引

本文档是 industry-penetration-analysis 技能的参考资源。当 SKILL.md 中 Phase 4 选定了分析模块后，按需加载本文档中对应模块的详细指引。

---

## 模块一：行业基本面认知

**适用场景**：读者不熟悉该行业，需要先建立对行业的基本认知。

**写作目标**：让读者理解这个行业是什么、怎么赚钱、客户为什么付钱。

**必须回答的问题**：

1. **行业解决什么问题**：不是"提供某某服务"这种空话，而是"如果没有这个行业，客户的什么需求无法满足"。

2. **客户是谁**：B端还是C端？如果B端，客户是哪个部门的什么人（CTO、采购经理、技术负责人）？

3. **客户为什么付钱**：是"不买就出问题"（刚需），还是"买了体验更好"（改善型）？是合规要求、效率提升、成本节约，还是收入增长驱动？

4. **产品或服务是什么**：有形的产品还是无形的服务？标准化还是定制化？

5. **产业链上下游是谁**：上游给什么、下游买什么。画出产业链简图（用文字描述，不要用图片）。

6. **行业怎么收费**：按次、按量、按年、按项目、按人数、按效果？单价水平是多少？

7. **收入和利润从哪里来**：主营收入是什么、其他收入是什么、各自的占比和毛利水平。

8. **核心成本是什么**：原材料、人工、研发、带宽、折旧、租金——哪个占比最大？哪个波动最大？

9. **行业过去的核心竞争力是什么**：技术、渠道、品牌、牌照、规模、成本、关系——哪些壁垒真的存在，哪些已经瓦解？

**常见错误**：
- 把"市场有多大"写在"行业是什么"前面——读者连行业都不懂，看到市场规模毫无意义。
- 罗列一堆术语不做解释——每出现一个专业词，当场解释。
- 写成公司业务介绍——要讲的是"行业里的企业一般怎么赚钱"，而不是"某公司怎么赚钱"。

## 模块二：产业链和利润池

**适用场景**：产业链较长、环节较多、公司分工复杂，需要分层理解价值分配。

**写作目标**：让读者理解产业链上谁赚走了大部分利润、为什么、以及变化发生时利润向哪个环节转移。

**必须回答的问题**：

1. **上游、中游、下游分别是谁**：可以用一句话概括各环节的核心角色。

2. **每个环节赚什么钱**：
   - 上游卖什么（原材料、设备、技术授权）？定价权在谁手里？
   - 中游做什么（制造、集成、服务）？是加价模式还是赚取服务费？
   - 下游买什么（产品、服务、解决方案）？下游的采购决策由什么驱动？

3. **谁承担风险**：库存风险、技术迭代风险、信用风险、政策风险——哪个环节承担最多？承担风险的环节是否获得了相应的回报？

4. **谁拥有定价权**：产业链中，哪个环节能主动调整价格而不丢失客户？定价权的基础是什么（技术壁垒、资源稀缺、品牌效应、渠道垄断、客户粘性）？

5. **谁利润率最高**：为什么？高利润率是可持续的还是暂时的？

6. **谁资本开支最重**：重资产环节在行业景气时弹性小（折旧吃掉利润），但在行业低迷时壁垒高（新进入者很难投资）。

7. **谁现金流最好**：现金流好的环节在下行周期中有更强的抗风险能力。

8. **行业变化时利润向哪个环节转移**：这是最有价值的分析——当需求、技术、政策变化时，产业链的价值分配会重新洗牌。哪些环节受益，哪些环节受损，为什么？

**写作方法**：不要写成"上游是A、中游是B、下游是C"的清单。要写出产业链的动态和张力——比如"上游掌握资源但承担了最多的资本开支，中游赚加工费但没有定价权，下游掌握客户但面临价格竞争"。

## 模块三：需求侧变化

**适用场景**：行业需求正在发生明显变化——增长、萎缩、结构转换。

**写作目标**：让读者理解需求从哪里来、为什么变化、变化是否可持续、变化是否能传导到利润。

**必须回答的问题**：

1. **需求来自哪些客户**：具体到客户类型、行业分布、区域分布。

2. **客户为什么买**：驱动客户采购的底层原因——是成本节约、效率提升、合规要求、还是竞争压力？这个原因在变化吗？

3. **客户采购预算来自哪里**：是客户的自有资金、融资、政府预算，还是下游客户支付的费用？预算来源的稳定性直接决定了需求的可持续性。

4. **需求增长是一次性、周期性还是结构性**：
   - **一次性**：疫情后的报复性消费、政策窗口期的集中采购——增长后会回落。
   - **周期性**：与宏观经济、库存周期、利率周期相关的波动。
   - **结构性**：消费习惯改变、技术升级、人口结构变化——增长是长期趋势。

5. **需求是否有价格敏感性**：客户对涨价的容忍度有多高？如果价格翻倍，需求会消失还是会接受？这决定了行业是否有提价空间。

6. **需求是否能传导为订单**：需求到订单之间有没有障碍（决策流程长、预算审批、合同谈判）？

7. **订单是否能传导为收入**：订单到收入之间有没有确认障碍（交付验收、收入确认政策）？

8. **收入是否能传导为利润**：收入增长时，利润增长的比例是高于还是低于收入增速？取决于固定成本与变动成本的比例。

**常见错误**：
- 只说"需求在增长"不说"为什么增长"。
- 把需求增长直接等同于利润增长——忽略了成本端的变化。
- 不区分一次性、周期性和结构性需求。

## 模块四：供给侧变化

**适用场景**：供给格局、产能、牌照、资源、技术门槛在变化。

**写作目标**：让读者理解供给是否稀缺、扩张能力、进入门槛、以及供给变化对价格和利润的影响。

**必须回答的问题**：

1. **供给是否稀缺**：在需求正常或增长的情况下，供给是充裕、均衡还是紧缺？

2. **扩产或扩服务能力需要多久**：
   - 轻资产行业（软件、服务）：扩产只需招人，周期短。
   - 重资产行业（制造、资源）：需要建厂、买设备、拿批文，周期长。
   - 高壁垒行业（牌照、专利）：扩产受外部条件限制。

3. **核心资源是什么**：技术、人才、牌照、品牌、渠道、资本、数据——哪种资源最关键？它是否容易被复制？

4. **进入门槛在哪里**：
   - 资金门槛：要投多少钱？
   - 技术门槛：需要什么技术积累？
   - 政策门槛：是否需要牌照或许可？
   - 客户门槛：客户转换成本高不高？
   - 规模门槛：新进入者能否在成本上与现有玩家竞争？

5. **老玩家能否快速扩张**：老玩家有资金、技术和经验优势，但可能面临管理瓶颈、资源限制或战略重心偏移。

6. **新玩家能否快速进入**：如果门槛低，高利润会吸引新玩家迅速进入，导致利润回归均值。

7. **如果供给跟得上，高利润可能难持续**：这是供给侧分析的核心——现在的高利润是因为供给受限，还是因为竞争格局健康？

8. **如果供给跟不上，龙头可能获得更强定价权**：供给越紧缺，龙头越有定价权，利润率越有可能持续高于行业平均。

## 模块五：价格和盈利中枢

**适用场景**：价格变化明显的周期品、资源品、服务业、制造业或基础设施行业。

**写作目标**：让读者理解价格由什么决定、当前价格变化的原因、价格与利润的传导关系。

**必须回答的问题**：

1. **价格由什么决定**：供需关系、成本加成、客户预算、国际定价、政策指导价、还是拍卖竞价？

2. **过去价格为什么涨或跌**：找出历史上价格变化的核心驱动因素——是需求波动、供给变化、成本推动，还是竞争格局变化？

3. **当前价格变化来自什么**：
   - 需求驱动？——需求是否可持续？
   - 供给驱动？——供给约束是否在缓解？
   - 成本驱动？——成本上涨是否不可逆？
   - 库存驱动？——库存周期有多长？
   - 政策驱动？——政策是一次性还是长期？
   - 竞争格局驱动？——格局变化是否可持续？

4. **价格变化能否持续**：判断的关键是看驱动因素是否具有持续性。

5. **价格如何影响毛利率**：价格提升直接拉动毛利率，但需要区分：是价格涨了而成本不变（毛利率弹性大），还是成本和价格一起涨（毛利率弹性小）。

6. **毛利率改善是否能变成净利润**：毛利率改善是净利润改善的前提，但费用端的变化（折旧增加、研发投入、销售费用、财务费用）可能吃掉毛利率改善的成果。

7. **费用、折旧、财务成本是否会吞掉利润弹性**：重资产行业在景气周期中，折旧和水电人工等固定成本会随产能利用率提升而摊薄，形成利润弹性放大的"杠杆效应"。但如果公司处于大规模资本开支周期，折旧和财务费用可能在价格/毛利率改善的同时侵蚀净利润。

## 模块六：技术和产品演进

**适用场景**：新技术、新产品、新工艺、新应用场景驱动行业变化。

**写作目标**：让读者理解新技术解决什么问题、替代了什么、客户为什么愿意换、落地进度到了哪一步。

**必须回答的问题**：

1. **新技术解决什么旧问题**：旧技术有什么痛点（效率低、成本高、性能差、场景受限）？

2. **它替代了什么**：是一个全新的产品（创造新需求），还是替代了旧产品（存量替代）？

3. **客户为什么愿意换**：
   - 性价比更高？——同等性能价格更低，或同等价格性能更高。
   - 不得不换？——旧技术被淘汰、供应中断、合规要求。
   - 新功能需要？——旧技术无法满足的新需求。

4. **新技术是否降低成本、提升效率、提高性能或打开新场景**：至少回答其中一点，并给出具体数据或案例。

5. **技术进步是否已经形成产品**：从实验室技术到可商用产品之间，还有多少差距？

6. **产品是否已经形成订单**：有没有客户实际在买？订单是验证性的还是规模化的？

7. **订单是否已经形成收入**：订单到收入需要交付周期，有些行业（如工程）需要数月到数年。

8. **收入是否已经形成利润**：新产品前期研发和推广费用高昂，可能在收入增长的同时侵蚀利润。需要看新产品的毛利率是否高于公司整体水平，以及收入占比是否足够大。

**判断路径**：技术→产品→订单→收入→利润。每一步之间都可能断裂。写清楚当前处于哪一步。

## 模块七：商业模式变化

**适用场景**：行业收费方式、收入确认方式或客户关系发生变化。

**写作目标**：让读者理解商业模式的改变是否真实、是否可持续、是否已经体现在财报中。

**必须回答的问题**：

1. **一次性收入是否变成持续收入**：从卖产品变成收服务费/订阅费。如果是，续费率是多少？客户生命周期价值是否提升？

2. **硬件销售是否变成软件/服务**：从卖硬件（一次性、低毛利）到卖软件/服务（持续、高毛利）。验证方式是软件/服务收入占比是否在提升。

3. **项目制是否变成平台化**：从每个项目单独交付（人力驱动、可复制性差）到平台化复用（产品驱动、边际成本低）。验证方式是毛利率是否在提升、交付周期是否在缩短。

4. **低毛利业务是否升级成高毛利业务**：通过产品升级、客户上移、增加增值服务实现。验证方式是各业务线的毛利率变化。

5. **客户粘性是否提升**：通过多产品绑定、数据沉淀、生态锁定实现。验证方式是客户流失率、续约率、多产品使用率。

6. **续费率、复购率、ARPU、订阅收入占比是否改善**：这些是商业模式变化的直接财务验证指标。

7. **商业模式变化是否真实进入财报**：变化停留在PPT层面还是已经在利润表、资产负债表、现金流量表中体现？

**重要提醒**：商业模式变化是行业分析中最容易被"讲故事"的部分。一定要找数据验证，而不是只听公司的战略说明。

## 模块八：竞争格局

**适用场景**：玩家角色、集中度、进入壁垒、海外对标变化明显。

**写作目标**：让读者理解行业玩家的分类、各自的优势和局限、谁可能崛起谁可能衰落。

**必须回答的问题**：

1. **行业玩家分几类**：按什么维度分类（规模、技术路线、客户类型、商业模式、资源禀赋）？分类要有区分度，能反映不同的竞争逻辑。

2. **每类玩家靠什么赚钱**：每一类玩家的核心竞争优势和盈利模式是什么？

3. **谁掌握客户**：客户关系具有排他性吗？客户转换成本高吗？

4. **谁掌握渠道**：渠道是开放的还是封闭的？渠道壁垒是否在变化？

5. **谁掌握技术**：技术壁垒有多高？技术是否在被追赶或替代？

6. **谁掌握产能**：产能有没有瓶颈？扩产需要多久？

7. **谁掌握牌照或资源**：政策壁垒是否在变化？

8. **谁可能被边缘化**：什么类型的玩家在行业变化中失去了原有优势？

9. **谁可能从配角变成核心**：什么类型的玩家在行业变化中获得了新的战略地位？

10. **海外对标能说明什么，不能说明什么**：
    - **能说明**：行业技术路径、商业模式演化方向、长期空间。
    - **不能说明**：估值水平、成长速度、竞争格局（不同市场的生态差异可能带来不同的行业结构与利润分配）。
    - 写对标时必须明确标注"可类比的部分"和"不可类比的部分"。

## 模块九：政策和监管

**适用场景**：政策影响明显的行业。

**写作目标**：让读者理解政策改变的是需求、供给还是格局，政策的影响是短期还是长期，是否已进入财报。

**必须回答的问题**：

1. **政策改变的是什么**：
   - 需求侧？——补贴刺激消费、政府集中采购、强制标准。
   - 供给侧？——准入限制、产能淘汰、环保约束。
   - 准入门槛？——牌照、资质、许可。
   - 价格机制？——指导价、限价、招标规则。
   - 补贴？——补贴力度、补贴期限、补贴对象。
   - 采购节奏？——提前采购还是推迟采购。
   - 竞争格局？——鼓励本土企业、限制外资。

2. **政策是一次性刺激还是长期制度变化**：
   - 一次性刺激：补贴退坡后需求可能回落。
   - 长期制度变化：法律、标准、准入门槛一旦建立，影响持久。

3. **政策是否已经进入订单和财报**：政策发布的时间和订单/收入的变化之间是否有因果关系？有些政策需要很长时间才能落地。

4. **政策是否可能带来反向约束**：比如补贴可能导致产能过剩，环保监管可能导致成本上升。

5. **市场是否把政策利好过度外推**：市场在炒作时容易忽略政策的执行难度、延迟和副作用。分析时要指出这些风险。

## 模块十：行业空间和天花板

**适用场景**：市场在讨论空间扩张、渗透率提升、新品类放量。

**写作目标**：让读者理解旧天花板在哪里、新增量来自哪里、新增量是否真实、新天花板是否真的比旧天花板高。

**必须回答的问题**：

1. **旧市场空间由什么决定**：渗透率、单价、使用频率、客户数量——哪个是天花板的主要限制？

2. **旧天花板为什么有限**：是渗透率饱和、单价下降、客户数量见顶、还是替代品出现？

3. **新增量来自哪里**：
   - 新客户？——从哪些客户来？客户数量空间有多大？
   - 新场景？——从哪些新应用场景来？场景的真实性验证了吗？
   - 新品类？——新产品还是老产品的新版本？
   - 市场区域拓展？——国内还是海外？
   - 提价？——为什么以前不提现在能提？

4. **新增量是扩大收入规模、提高单价、提升毛利率、还是改变收费方式**：
   - 扩大收入规模：需要多少新增量才能抵消旧业务的衰退？
   - 提高单价：客户能否接受？
   - 提升毛利率：收入结构变化带来的还是价格上涨带来的？
   - 改变收费方式：从一次性到持续（订阅）会改变收入模式的时间分布。

5. **新增量中哪些已经验证，哪些只是预期**：
   - 已验证：已经有收入、订单、客户数据支撑。
   - 预期：基于假设、推测、海外对标。
   - 必须明确标注每部分属于哪种状态。

6. **新天花板是否真的比旧天花板更高**：用具体数字论证，而不是说"空间打开了"。

7. **如果新逻辑不成立，行业会回到什么状态**：这是压力测试——在最差情况下，行业的底线在哪里？

## 模块十一：验证与证伪指标

**这是每一个行业穿透分析都必须写的模块。**

**适用场景**：任何行业分析的最后，都需要告诉读者"未来看什么"。

**写作目标**：列出具体的、可跟踪的行业指标，帮助读者验证或证伪文章中的关键判断。

**指标选择原则**：

1. **与主问题直接相关**：每个指标都必须能验证或证伪文章的核心判断，不是为了凑数。

2. **具体可度量**：不要写"关注行业变化"，要写"关注行业月度均价"。

3. **区分领先和滞后指标**：订单是领先指标，收入是滞后指标；价格情绪是领先指标，毛利率是滞后指标。

4. **设置证伪条件**：什么情况下你的判断会被推翻？这是最有价值的部分。

**常见的行业指标类型**：

| 指标类型 | 示例 | 说明 |
|---------|------|------|
| **价格指标** | 行业均价、产品单价、服务费标准 | 最直接反映供需和定价权变化 |
| **毛利率指标** | 行业平均毛利率、头部厂商毛利率 | 反映行业盈利中枢变化 |
| **订单指标** | 新签订单金额、在手订单、订单增速 | 领先于收入，反映需求变化 |
| **产能指标** | 产能利用率、开工率、库存水平 | 反映供需平衡状态 |
| **客户指标** | 续约率、客户流失率、ARPU、新客获取成本 | 反映客户粘性和付费意愿 |
| **资本开支指标** | 行业CapEx增速、扩产计划 | 反映供给侧对未来需求的判断 |
| **渗透率指标** | 产品渗透率、新场景渗透率 | 反映增长空间 |
| **收入结构指标** | 新业务收入占比、高毛利业务占比 | 反映商业模式变化是否落地 |
| **市场份额指标** | CR3、CR5、龙头份额变化 | 反映竞争格局变化 |
| **海外对标指标** | 海外龙头业务增速、海外同行业绩 | 提供产业演进方向的参考 |
| **政策执行指标** | 采购招标公告、项目开工率、补贴发放进度 | 验证政策是否落地 |

**证伪条件示例**：
- "如果XX价格在6个月内回落至涨价前水平，则本文'定价权转移'的判断被证伪。"
- "如果XX新业务收入占比连续两个季度下降，则本文'商业模式升级'的判断需修正。"
- "如果XX客户开始大规模自建替代方案，则本文'客户粘性提升'的判断不成立。"
