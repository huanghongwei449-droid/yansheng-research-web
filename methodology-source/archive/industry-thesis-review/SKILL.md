# 行业/主题研报穿透分析

## 工作方式

接到一个行业/主题后，不按卖方研报的叙事顺序复述——而是围绕6个底层问题，把卖方多份报告的核心信息拆解后重新组装。

```
问题1：解决什么 → 问题2：为什么变化 → 问题3：推动力是否在 → 问题4：谁核心谁概念 → 问题5：业绩能否验证 → 问题6：估值是否充分
```

每一步的结论直接喂给下一步。最终产出一份能让读者理解"这个产业主题到底靠不靠谱、核心标的在哪里、现在什么位置"的分析。

## 数据源

先扫用户指定的知识库中该行业/主题相关的所有卖方报告，再用web搜索补充最新数据和公告。

| 信息源 | 看什么 |
|--------|--------|
| 知识库中的卖方电话会纪要/研报 | 核心逻辑、产业数据、标的推荐、估值判断 |
| 知识库中的标的调研纪要 | 公司口径、订单/客户/毛利率一手信息 |
| web搜索：最新业绩公告 | Q1/Q2数据、业绩预告验证卖方逻辑 |
| web搜索：股价/估值数据 | 当前PE、市值、近期走势、资金流向 |
| web搜索：产业政策 | 近期政策文件、补贴/关税/标准变化 |

## Phase 1：提取卖方核心观点

从知识库中找到该行业/主题相关的卖方研报和电话会纪要。找出最近期的几份（特别是同一团队反复推的系列报告），提取：

- 卖方最核心的判断是什么（一句话）
- 他们推荐的标的和排序
- 支撑逻辑的关键数据（市场空间、增速、配比等）
- 卖方给出的估值/目标价

## Phase 2：按6个问题重组

### 问题1：到底解决什么问题

不是"这个行业做什么"，而是"它在产业链中解决了什么瓶颈"。好的产业主题往往对应一个具体的痛点。

- 这个环节在产业链中处于什么位置
- 它解决了谁、在什么场景下的什么问题
- 有没有具体案例或数据说明这个问题的严重性/紧迫性
- 如果这个问题不解决，对产业链的后果是什么

### 问题2：为什么会带来这些变化

解释变化的底层机制，不是列数字。

- 什么因素在驱动变化（技术迭代/架构变革/政策强制/成本曲线下降）
- 变化的具体机制：A变了→B不得不变→C用量跳升。每一步要有因果
- 量是怎么变的、价是怎么变的、两者之间有没有互相加强的关系
- 这个变化是结构性的还是周期性的

### 问题3：当前政策、产业和资本开支是否正在推动

用三类证据检验方向不是"将来可能发生"而是"正在发生"。

- 政策端：近期有无明确的政策文件、攻关目录、补贴标准
- 产业端：龙头公司Q1/Q2业绩是否验证了方向。列举具体公司的具体数据
- 资本开支端：下游大客户是否在增加相关领域的采购/投资。合同负债、预付款、招标等信息

### 问题4：哪些公司只是概念，哪些是核心标的

把卖方推荐池中的公司分层，不搞"都推荐"。

- 纯正核心：业务集中在该赛道、市占率高、有订单验证
- 重要但不纯：有该业务但占比不高，或弹性被其他业务稀释
- 概念相关：有布局但尚未产生收入，或只是在产业链边缘

分层标准要写清楚，让读者能看到"为什么A是核心而B不是"。

### 问题5：核心标的数据能否验证逻辑

对核心标的逐一检验。

- 收入：该业务收入体量和增速
- 订单/客户：具体大客户是谁、订单规模、合作模式
- 毛利率：趋势是升还是降、什么原因
- 业绩弹性：如果行业逻辑兑现，利润能到什么水平
- 引用最新季报/中报数据做验证

### 问题6：当前估值是否已充分反映预期

- 各标的当前市值、PE(TTM)、2026/2027E前瞻PE
- 和可比公司/板块的估值对比
- 卖方给出的目标价 vs 当前股价的空间
- 判断当前price in了多少预期：已经price in乐观远期/合理反映/存在预期差
- 如果超前反映了，回落到什么PE区间才有安全边际

## 输出格式

```markdown
# [卖方/主题名称]——行业穿透分析

> 基于[来源] | [时间]

## 一、到底解决什么问题

## 二、为什么会带来这些变化

## 三、当前政策、产业和资本开支是否正在推动

## 四、哪些公司只是概念，哪些是核心标的

## 五、核心标的数据能否验证逻辑

## 六、当前估值是否已充分反映预期

---

*数据来源：[列出具体来源]*
```

## 工作流示例

### 示例1：交换机行业

```
用户："把开源证券关于交换机的观点分析清楚"

1. 搜索知识库中开源通信团队近期的交换机相关报告和电话会纪要
2. 找到核心三份材料：7/1超节点电话会、6/30交换机通胀、5/6四剑客
3. 提取核心观点：超节点→交换芯片配比1:20→1:2、英伟达Spectrum-X成冠军、Q1产业链验证
4. 围绕6个问题重组
5. 对四剑客分层：盛科最纯(交换芯片)、锐捷次之(白盒交换机绑定字节)、紫光重要但不纯、中兴太杂
6. 输出
```

### 示例2：机器人轻量化材料

```
用户："分析一下机器人轻量化材料这个方向，镁合金和PEEK到底靠不靠谱"

1. 搜索知识库中的机器人轻量化深度报告、镁合金产业报告、T链专家交流
2. 提取核心观点：镁合金vs铝vs PEEK各自的定位、降重幅度、成本对比
3. 问题1：Optimus对自重的敏感度→每减重10%续航+15-20%
4. 问题2：半固态压铸工艺成熟→镁合金从易燃变成可控→规模化拐点
5. 问题3：T链专家确认铝镁合金是Optimus核心方向、主机厂已定点
6. 问题4：永茂泰/宝武镁业/旭升等分层
7. 输出
```
