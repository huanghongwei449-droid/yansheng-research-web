# 买方深度研究（通用投资文章版）

## 一、定位：回答“为什么现在要研究这家公司”

你不是在写公司百科，不是在堆业务表、财务表和估值表，也不是在复述卖方研报。你要写的是一篇买方投资文章，回答：

> 这家公司现在的市场争议是什么？市场在给它什么预期？这个预期能不能兑现？如果兑现，空间来自哪里；如果不能兑现，风险在哪里？

用户读完后应该知道：

1. 公司到底靠什么赚钱；
2. 为什么过去市场这样看它；
3. 现在发生了什么变化；
4. 变化如何传导到收入、毛利、费用、利润和现金流；
5. 公司和可比对象到底哪里相同、哪里不同；
6. 当前市值隐含了什么预期；
7. 买它是在买什么，错了会错在哪里。

最终输出必须是一篇有主线、有判断、有逻辑、有可读性的文章，而不是资料堆叠。

---

## 二、通用写作原则

### 1. 开篇必须提出投资争议

不要一上来介绍公司历史。先写清楚这家公司为什么现在值得研究。

常见争议包括：

- 低估值是不是陷阱；
- 高估值是否有业绩支撑；
- 困境反转是否真实；
- 主题催化能否落到业绩；
- 现金很多但主业弱，应该怎么定价；
- 收入增长很好但利润差，经营杠杆能否释放；
- 利润很好但现金流差，质量是否有问题；
- 行业有变化，但公司是否真受益；
- 股价涨很多后还能不能买。

开篇要把研究问题讲清楚，让读者知道全文围绕什么判断展开。

### 2. 公司介绍必须服务于投资判断

不能写成百科。必须解释：

- 公司最初靠什么起家；
- 现在收入和利润主要来自哪里；
- 哪块业务决定收入规模；
- 哪块业务决定利润质量；
- 哪块业务决定估值想象；
- 哪块业务只是补充或拖累；
- 公司能力是自研、收购、渠道、牌照、资源、客户关系，还是周期红利带来的。

### 3. 每个业务都要讲清楚“赚钱机制”

对核心业务必须用连续文字讲明白：

- 产品或服务到底是什么；
- 客户是谁；
- 客户为什么必须买；
- 这笔钱来自客户什么预算；
- 公司如何收费；
- 收入增长来自量、价、渗透率、客户数、ARPU、产品结构还是一次性事件；
- 毛利率为什么高或低；
- 费用是否刚性；
- 什么指标能验证它真的变好。

不能只列“收入占比、毛利率、增速”。

### 4. 财务分析必须讲成“利润发动机”

财务部分要回答利润是怎么被制造出来的。

必须拆：

**收入来源 → 成本结构 → 毛利率变化 → 销售/研发/管理费用 → 扣非利润 → 非经常性损益 → 经营现金流 → 资产负债表风险。**

每一个关键变化都必须解释原因：

- 收入增长是周期恢复、价格上涨、份额提升、并表、订单释放，还是口径变化？
- 毛利率变化是涨价、产品结构、原材料、产能利用率、会计口径，还是一次性因素？
- 利润增长是主业增长、费用率下降、投资收益、汇兑、补贴，还是减值转回？
- 现金流是否跟利润匹配？
- 应收、存货、合同负债、商誉、资本开支是否支持或否定利润质量？

### 5. 行业变化必须落到公司变量

不能写“行业景气，公司受益”。必须写清楚：

- 行业变化改变了哪些客户的采购行为；
- 公司在哪个环节接到订单；
- 订单如何确认收入；
- 收入是否能提高毛利率；
- 毛利是否会被费用吞掉；
- 财报上最先看到哪个指标；
- 如果逻辑错了，会在哪个指标上暴露。

### 6. 可比公司必须先解释，再比较

可比公司不是用来堆表的。必须先说明：

- 这个可比公司是什么类型；
- 为什么能比；
- 哪些地方不能比；
- 市场给它什么资产属性；
- 它对本公司的估值锚意义是什么。

比较维度至少包括：

- 业务本质；
- 客户结构；
- 收费模式；
- 毛利率；
- 费用率；
- 增速；
- 现金流；
- 估值方法；
- 资产属性。

### 7. 估值必须反推市场预期

不能只写 PE、PB、PS 或目标价。必须从市值反推：

- 当前市值对应多少收入、利润和净利率；
- 市场隐含了多高增速；
- 当前估值要求公司兑现什么；
- 哪些预期已经 price-in；
- 哪些预期还没有验证；
- 如果核心变量成立，利润和估值怎么变；
- 如果只兑现一半，当前股价是否还能撑住；
- 如果证伪，下跌来自利润下修还是估值压缩。

### 8. 结论必须有买方态度

不能写“建议关注”。必须清楚回答：

- 买它到底买的是什么；
- 不买它的理由是什么；
- 现在是高胜率、低赔率，还是低胜率、高赔率；
- 未来 1-2 个财报期看什么；
- 什么数据出现后应该提高信心；
- 什么数据出现后应该承认逻辑错了。

## 三、通用研究流程

### Phase 0：提出核心投资问题

开篇用几段话写：

> 这家公司当前不是简单的好公司/坏公司问题，而是市场是否应该重新给它定价的问题。过去它被当成某类资产，现在市场可能开始按另一类资产看它。本文要判断的是，这种定价切换有没有基本面支撑。

实际写作时必须根据公司情况重写，不得套用这句话。

### Phase 1：把公司放回生意里

用文章方式讲：

1. 公司靠什么起家；
2. 现在业务结构是什么；
3. 每块业务服务谁；
4. 客户为什么付钱；
5. 公司如何收费；
6. 哪块业务决定收入；
7. 哪块业务决定利润；
8. 哪块业务决定估值弹性。

如果业务复杂，可以配一张简表，但表前和表后都必须有文字解释。

### Phase 2：还原业务来源和壁垒

必须解释公司能力怎么来的：

- 自研长期积累；
- 并购整合；
- 客户迁移；
- 政策准入；
- 渠道网络；
- 资源禀赋；
- 产能建设；
- 供应链能力；
- 管理层战略调整。

不能把业务当成天生存在。来源决定壁垒，壁垒决定估值。

### Phase 3：拆利润发动机

用连续文字先讲利润逻辑，再给核心财务表。

重点判断：

- 表观利润和真实经营利润是否一致；
- 扣非利润是否支持主业改善；
- 经营现金流是否支持净利润；
- 应收和存货有没有提前透支风险；
- 毛利率变化能否持续；
- 费用率下降有没有天花板；
- 资产负债表有没有隐藏风险；
- 现金、理财、投资收益是否应该单独估值。

### Phase 4：把行业变化映射到公司

围绕 1-3 个核心变量写：

- 行业变化是什么；
- 这个变化为什么会让客户买公司的产品；
- 公司为什么能拿到订单，而不是竞争对手拿；
- 订单会不会变成收入；
- 收入会不会变成利润；
- 利润是否有现金流；
- 这个过程需要多久；
- 什么指标验证。

### Phase 5：重建可比公司和资产属性

先解释可比对象，再判断公司应该按什么资产定价：

- 成长股；
- 价值股；
- 现金牛；
- 平台型公司；
- 周期反转；
- 困境反转；
- 事件驱动；
- 主题成长；
- 高分红资产；
- 资源品；
- 制造业龙头；
- 软件/SaaS；
- 硬件设备商；
- 项目制公司。

资产属性不同，估值方法不同。不能简单拿一个 PE 或 PS 下结论。

### Phase 6：市值隐含预期

必须写成文章判断：

> 当前市值不是一个静态数字，而是市场对未来收入、利润率、增长持续性和资产属性的投票。

需要回答：

- 当前价格已经相信了什么；
- 当前价格还没有相信什么；
- 最关键的预期差在哪里；
- 市场错了会错在哪里；
- 你和市场分歧在哪里。

### Phase 7：情景和买方结论

情景不是机械乐观/中性/悲观，而是围绕核心变量：

- 核心变量 A 成立时，收入/利润/估值如何变化；
- A 只兑现一半时，当前估值是否合理；
- A 被证伪时，风险多大；
- 第二变量是否能补偿第一变量；
- 最后给出买方操作倾向。

## 四、推荐输出结构

```markdown
# [公司]买方深度研究：市场在赌什么，兑现靠什么

## 引言：为什么现在要研究这家公司
提出市场争议和研究问题。

## 一、这家公司到底靠什么赚钱
用文章讲业务、客户、收费方式、收入来源和利润来源。

## 二、这家公司过去为什么被这样定价
讲历史、旧叙事、市场偏见或估值锚。

## 三、现在发生了什么变化
解释行业、公司、财务、竞争、政策或资本市场变量的变化。

## 四、变化如何进入利润表
拆收入、毛利、费用、扣非、现金流和资产负债表。

## 五、它到底该和谁比
解释可比公司和资产属性，不机械套估值。

## 六、当前市值隐含了什么预期
反推市场预期、price-in 和未验证部分。

## 七、买方结论：买的是什么，错的风险是什么
给出判断、验证指标和证伪条件。
```

## 五、质量检查清单

输出前必须确认：

- 是否提出了明确投资争议？
- 是否写成文章，而不是表格拼接？
- 是否解释了公司为什么赚钱？
- 是否拆清楚利润发动机？
- 是否区分表观利润、扣非利润、现金流和一次性因素？
- 是否把行业变化落到公司订单和利润？
- 是否解释了可比公司为什么可比、为什么不可比？
- 是否从市值反推了预期？
- 是否说清楚买它买什么、错了错在哪里？
- 是否避免机械套用示例行业和示例公司？
