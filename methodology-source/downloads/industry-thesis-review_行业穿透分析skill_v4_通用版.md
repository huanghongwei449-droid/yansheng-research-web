# 行业/主题研报穿透分析（通用文章版）

## 一、定位：这不是资料整理，而是“把行业讲通”

你要写的不是考试答案，不是卖方研报摘要，也不是产业链资料合集，而是一篇让金融背景读者能够真正读懂行业变化的研究文章。

读者有投资、财务、估值基础，但可能完全没有该行业经验。你的任务是把行业语言翻译成投资语言：这个行业原来是什么情况，现在发生了什么变化，为什么变化会发生，变化如何传导到订单、价格、毛利、利润、估值和核心公司。

最终输出必须是一篇完整文章。文章要有开头、有铺垫、有转折、有因果、有判断、有结论。不能写成“A123、B123”的答题结构。

---

## 二、最重要的通用原则

### 1. 所有行业都必须先讲“旧世界”，再讲“新变化”

无论研究的是 CDN、机器人、半导体、军工、创新药、消费、光伏、储能、AI 应用、算力、金融 IT、化工、地产链，写作顺序都必须是：

**旧世界是什么样 → 为什么过去市场这么定价 → 哪个变量发生变化 → 客户/供给/价格/竞争如何变化 → 谁最受益 → 如何验证 → 投资含义。**

不能一上来写“行业迎来拐点”“AI 推动”“国产替代加速”“景气度提升”。这些都是结论，不是分析。

### 2. 第一次出现的专业词必须解释

任何行业外读者可能不懂的词，第一次出现时必须解释清楚。解释不是给定义，而是讲它在商业链条中的作用：

- 它解决什么问题；
- 谁需要它；
- 为什么愿意付钱；
- 它替代了什么旧方案；
- 它如何变成上市公司的收入和利润。

错误写法：

> 边缘推理带来第二增长曲线。

正确写法：

> 传统推理通常在中心云完成，但当应用需要更低延迟、更高并发或更强隐私保护时，部分计算会被放到离用户更近的节点上完成，这就是边缘推理。它对相关公司的意义不在于多了一个概念，而是原来只负责传输、存储或连接的节点资产，可能开始承担计算任务，从而带来新的收费方式和更高毛利的服务。

### 3. 所有因果链必须补全中间环节

禁止写跳跃链条：

> AI 爆发 → 行业需求提升 → 公司受益。

必须补全：

**技术/政策/需求变化 → 改变了谁的行为 → 行为变化导致采购什么 → 采购如何形成订单 → 订单如何形成收入 → 收入如何影响毛利率/费用率/利润 → 财报上看什么验证。**

如果中间任何一环讲不清楚，就不能直接下“受益”结论。

### 4. 不准用表格代替分析

表格只能在文字讲透之后用来总结。正文最多使用 3 张核心表格：

1. 旧世界 vs 新世界；
2. 核心公司定位对比；
3. 逻辑验证与风险指标。

不能用表格解释读者本来就不懂的东西。越是关键概念，越要用连续文字讲。

### 5. 不准把示例当模板

本文档里出现的任何行业、公司或概念都只是示例。实际写作时必须根据当前研究对象重建逻辑，不得机械套用示例里的行业词、公司名、对标对象或结论。

如果研究对象不是 CDN，就不要写 CDN；如果不是机器人，就不要写机器人；如果不是 AI，就不要强行写 AI。

## 三、通用分析框架：所有行业都可以套这条主线

### Phase 0：确定这篇文章真正要回答的问题

开篇先找出研究问题，而不是直接介绍行业。

好的研究问题通常长这样：

- 这个行业为什么过去不被市场喜欢，现在为什么重新被看见？
- 这是短期主题炒作，还是真实的产业变化？
- 变化来自需求、供给、价格、政策、技术，还是竞争格局？
- 这个变化能不能落到业绩？
- 哪些公司是真正受益，哪些只是概念映射？

开头要用 3-5 段话把研究问题铺开，让读者知道这篇文章不是资料汇总，而是在解决一个投资争议。

### Phase 1：讲清楚行业的“旧世界”

必须用连续文字讲清楚：

1. 这个行业最初解决什么问题；
2. 客户是谁，为什么付钱；
3. 行业过去的收入模式是什么；
4. 行业过去的利润来源是什么；
5. 过去为什么增长有限、估值低、价格战、周期性强或壁垒不清；
6. 过去的竞争格局如何形成；
7. 过去市场为什么按这种方式给它定价。

这一部分的目标是让读者知道：**如果没有新变化，这个行业本来应该被怎么看。**

### Phase 2：找到变化发生的真正起点

所有产业变化，本质上通常来自以下几类变量之一，必须判断清楚是哪一种：

- 需求变化：客户突然需要更多、更快、更高质量或更合规的产品；
- 供给变化：落后产能出清、海外玩家退出、竞争者收缩、产能受限；
- 价格变化：供需关系变化、低价竞争结束、产品升级带来提价；
- 技术变化：新技术让旧资产、旧渠道或旧客户关系重新有价值；
- 政策变化：政策让客户必须买，或让某类供给被限制；
- 商业模式变化：一次性项目变成订阅，硬件变成软件，卖产品变成卖服务；
- 竞争格局变化：原有龙头退出、新进入者受限、集中度提升；
- 资本开支变化：下游客户预算周期发生变化。

必须回答：

> 过去为什么不行？现在到底哪个变量变了？这个变量为什么足够重要？

### Phase 3：把变化写成完整商业传导链

每条主逻辑都必须写成段落，不得只用箭头图。

每条传导链都要回答：

1. 变化源头是什么；
2. 它影响了哪类客户或供给方；
3. 客户行为或竞争行为发生了什么变化；
4. 这种变化为什么会带来订单、价格、份额或毛利率变化；
5. 哪类公司最先受益；
6. 财报上最先看到哪个指标变化；
7. 什么情况出现说明这条逻辑不成立。

通用表达方式：

> 这个变化真正重要的地方，不是“行业有新概念”，而是它改变了客户的采购优先级。过去客户只愿意为 A 付钱，现在因为 B 的出现，客户必须重新采购 C。C 对上市公司的意义是，它要么提高收入规模，要么改善价格，要么改变产品结构，要么摊薄固定费用。只有当这些变化进入财报，产业逻辑才算从故事走向业绩。

### Phase 4：解释新概念和旧业务的关系

任何行业新概念都不能孤立写。必须说明它和旧业务是什么关系：

- 是旧产品升级？
- 是旧客户买新产品？
- 是同一批资产的新用途？
- 是完全新的收入曲线？
- 是只改变估值叙事，还是能改变利润表？
- 是公司已经有能力，还是还需要新投入？

如果新概念不能带来客户、订单、收入、利润或估值锚变化，就只能归为主题映射，不能当作核心逻辑。

### Phase 5：讲清楚竞争格局和核心公司

介绍任何公司之前，必须先说明它是谁、处在哪个环节、为什么重要。

竞争格局必须回答：

1. 行业玩家分几类；
2. 每类玩家靠什么赚钱；
3. 谁拥有关键资源；
4. 谁客户质量更好；
5. 谁毛利率和现金流更好；
6. 谁最受益于新变化；
7. 谁只是概念相关；
8. 为什么不能简单把海外公司估值照搬到 A 股公司。

可比公司不是用来堆 PE/PS 的，而是用来判断资产属性：这家公司到底应该被当成周期股、成长股、平台型公司、现金牛、困境反转、事件驱动，还是主题概念。

### Phase 6：重估行业天花板

不能只说“空间很大”。必须讲清楚：

1. 旧市场空间是多少，增长为什么有限；
2. 新增量来自哪几块；
3. 每块增量的假设是什么；
4. 哪些已经有财报或订单验证；
5. 哪些只是预期；
6. 乐观、中性、悲观情况下行业空间如何变化；
7. 天花板提升最终体现在哪些公司的收入和利润里。

### Phase 7：落到投资含义

最后必须回答：

- 当前市场到底在交易什么；
- 哪些逻辑已经被股价反映；
- 哪些逻辑还没验证；
- 哪些公司是真核心；
- 未来一个季度、半年、一年应该看什么；
- 什么数据出现说明逻辑成立；
- 什么数据出现说明只是概念炒作。

## 四、推荐输出结构

必须写成文章，可以按以下结构：

```markdown
# [行业/主题]深度研究：旧世界为什么变了，新世界能否兑现

## 引言：为什么这个行业突然值得重新研究
用连续段落提出研究问题和市场争议。

## 一、旧世界：这个行业原来靠什么赚钱，为什么过去市场这么看它
讲清楚行业原始功能、客户、收入模式、利润模式、竞争格局和过去估值逻辑。

## 二、变化起点：到底是哪一个变量变了
从需求、供给、价格、技术、政策、商业模式、竞争格局中找出真正变化。

## 三、传导链：变化如何一步步变成订单、价格、毛利和利润
用文章段落写完整因果链，必要时配一张简表。

## 四、新概念与旧业务：这不是贴标签，而是旧资产/旧客户/旧能力的新用途
解释新概念和原有业务的关系，判断是否能落到业绩。

## 五、竞争格局：谁是真正核心，谁只是概念相关
先解释公司类型，再比较核心公司。

## 六、天花板与估值含义：行业空间是否真的被打开
解释旧空间、新增量、假设和验证程度。

## 七、结论：这个行业现在到底在交易什么
给出投资判断、核心标的、验证指标和证伪条件。
```

## 五、质量检查清单

输出前必须自检：

- 读者不知道这个行业，也能读懂吗？
- 是否先讲了旧世界，再讲新变化？
- 是否解释了所有关键术语？
- 是否补全了因果链中间环节？
- 是否说明了客户为什么买、钱从哪里来？
- 是否讲清楚变化如何进入收入、毛利、利润？
- 是否说明了哪些是事实，哪些是预期？
- 是否区分了核心公司和概念公司？
- 是否有完整文章感，而不是答题感？
- 是否避免机械表格和 emoji？
