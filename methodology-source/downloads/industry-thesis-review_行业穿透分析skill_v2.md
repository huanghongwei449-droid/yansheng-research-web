# 行业/主题研报穿透分析 V2：白话产业翻译版

## 一、定位

本 skill 只解决一个问题：**把一个行业/主题讲清楚，并判断哪些公司是真正受益，哪些只是概念相关。**

它不是卖方研报摘要，也不是政策汇编。它必须服务买方判断：

> 这个行业到底解决什么问题 → 为什么现在发生变化 → 谁在付钱 → 订单和利润怎么传导 → 哪些公司最核心 → 数据是否验证 → 估值是否已经反映。

---

## 二、最高优先级原则

### 1. 必须先写“行业白话翻译层”

假设读者有金融基础，但没有产业经验。开头必须先回答：

| 问题 | 要求 |
|---|---|
| 这个行业一句话是什么 | 用商业语言，不用术语堆砌 |
| 它解决什么痛点 | 必须是客户真实痛点，不是行业口号 |
| 谁是付钱的人 | 客户是谁，预算来自哪里 |
| 为什么现在变化 | 政策、技术、成本、需求、供给、竞争、替代，哪一个真的变了 |
| 钱如何传导 | 客户预算 → 订单 → 收入 → 毛利率 → 利润 |
| 哪个环节最赚钱 | 硬件、软件、服务、渠道、平台、资源、运营，分别说清楚 |
| 哪些指标能验证 | 订单、招标、收入、合同负债、毛利率、库存、价格、客户资本开支等 |

禁止一上来就写“政策支持、空间广阔、景气度提升”。

必须写成：

```text
变化A发生
  → 客户B必须改变采购/生产/投入
  → 产业链C环节需求增加
  → 公司D收入/毛利/利润变化
  → 股价交易E预期
```

### 2. 行业分析不是概念解释，必须落到“谁真受益”

每个主题都要区分：

| 层级 | 定义 |
|---|---|
| 纯正核心 | 收入和利润直接来自该产业变化，且弹性最大 |
| 重要但不纯 | 有相关业务，但只是部分受益，或者弹性被其他业务稀释 |
| 概念相关 | 有故事、公告、合作或小业务，但短期难以体现在利润 |
| 蹭概念 | 只有题材关联，收入利润传导不清楚 |

必须说明分层标准，不允许只列股票池。

### 3. 对证据进行分级

| 证据等级 | 类型 | 作用 |
|---|---|---|
| 强证据 | 财报、公告、订单、招标、中标、合同、政策原文 | 可作为结论基础 |
| 中强证据 | 行业数据库、协会数据、龙头资本开支、客户采购计划 | 验证行业趋势 |
| 预期证据 | 券商研报、盈利预测、目标价、电话会观点 | 说明市场预期 |
| 弱证据 | 调研传闻、产业链口径、专家访谈、社媒纪要 | 只能作为线索 |
| 叙事参考 | 海外对标、未上市公司估值、远期空间测算 | 只说明想象空间，不等于当期估值 |

## 三、工作流程

## Phase 0：定义行业/主题边界

先确认研究对象到底是什么。

必须回答：

| 问题 | 内容 |
|---|---|
| 主题名称 | |
| 产业链范围 | 上游/中游/下游包括哪些环节 |
| 本次重点 | 是看全产业链，还是只看某个环节 |
| 市场当前交易点 | 政策、业绩、订单、涨价、国产替代、AI、出海、周期反转等 |
| 最关键争议 | 需求真假、弹性大小、竞争格局、估值是否透支等 |

---

## Phase 1：提取卖方核心观点，但不能停留在摘要

找到最近期卖方研报、电话会、产业纪要后，提取：

- 卖方最核心判断，一句话。
- 推荐标的和排序。
- 支撑逻辑的关键数据。
- 卖方给出的盈利预测、估值、目标价。
- 卖方没有讲清楚或可能过度乐观的地方。

输出：

| 卖方观点 | 支撑证据 | 证据等级 | 可能的问题 |
|---|---|---|---|

## Phase 2：按六个底层问题重组

# 问题1：这个行业到底解决什么问题？

不是行业“做什么”，而是客户为什么愿意掏钱。

必须写：

| 维度 | 回答 |
|---|---|
| 客户痛点 | 具体痛在哪里 |
| 过去怎么解决 | 原来的方案是什么 |
| 现在为什么不够用 | 成本、效率、性能、合规、安全、供给变化等 |
| 新方案解决什么 | 新技术/新产品/新模式的价值 |
| 谁付钱 | 预算来源 |
| 付钱意愿强不强 | 刚性/半刚性/可选消费/周期性 |

# 问题2：为什么现在发生变化？

必须解释底层机制，不允许只写“政策催化”。

按链条写：

```text
政策/技术/成本/需求/供给变化
  → 客户行为变化
  → 产业链订单变化
  → 价格/毛利率/份额变化
  → 公司业绩变化
```

同时判断变化性质：

| 变化类型 | 判断 |
|---|---|
| 一次性催化 | 只能带来短期交易 |
| 2-3年产业趋势 | 可以支撑中期成长 |
| 长期商业模式变化 | 可能带来估值体系切换 |
| 伪变化 | 只有口号，没有订单和利润 |

# 问题3：政策、产业、资本开支是否正在推动？

三类证据分别看：

| 维度 | 看什么 | 结论 |
|---|---|---|
| 政策 | 文件、时间表、预算、强制性 | 是口号还是硬约束 |
| 产业 | 龙头订单、招标、中标、价格、产能 | 是否真的发生 |
| 资本开支 | 下游客户预算、建设周期、采购节奏 | 钱是否真的到位 |

必须判断：**这是“预期阶段”，还是已经进入“订单/业绩验证阶段”。**

# 问题4：谁核心，谁只是概念？

必须建立分层标准。建议使用四个标准评分：

| 标准 | 说明 |
|---|---|
| 收入相关度 | 该主题收入占比高不高 |
| 利润弹性 | 该业务是否能显著贡献利润 |
| 竞争地位 | 是否是龙头/核心供应商/不可替代环节 |
| 验证难度 | 是否能从财报或订单中验证 |

输出：

| 公司 | 分层 | 受益环节 | 收入相关度 | 利润弹性 | 核心验证指标 | 为什么 |
|---|---|---|---|---|---|---|

# 问题5：业绩能否验证逻辑？

不能只说“未来空间大”。必须回到财报。

对核心标的逐一检验：

| 公司 | 收入是否体现 | 订单/合同负债是否体现 | 毛利率是否改善 | 费用率是否吞噬利润 | 现金流是否支持 | 结论 |
|---|---|---|---|---|---|---|

判断逻辑状态：

- **已验证**：收入、订单、利润或现金流已经出现。
- **验证中**：出现初步迹象，但仍需1-2个季度确认。
- **待验证**：只有产业叙事或券商预测。
- **已证伪**：数据明显不支持。

# 问题6：估值是否已充分反映？

估值不能只看PE。要结合行业阶段和公司类型。

必须回答：

| 问题 | 要求 |
|---|---|
| 市场现在在买什么 | 成长、修复、红利、资产、主题、周期、困境反转 |
| 当前估值隐含什么 | 反推收入/利润/份额/毛利率假设 |
| 哪些已经price-in | 已被股价反映的预期 |
| 哪些还没price-in | 潜在预期差 |
| 哪些可能被高估 | 过度线性外推、海外映射、概念溢价 |
| 最大证伪指标 | 哪个数据出来会让逻辑失效 |

## 四、公司对比规则

行业内公司对比必须用同一组维度，不能只比估值。

| 维度 | 公司A | 公司B | 公司C | 投资含义 |
|---|---|---|---|---|
| 业务本质 | | | | |
| 客户是谁 | | | | |
| 收入模式 | | | | |
| 毛利率 | | | | |
| 费用率 | | | | |
| 现金流 | | | | |
| 核心增长变量 | | | | |
| 风险来源 | | | | |
| 市场交易逻辑 | | | | |
| 估值差异原因 | | | | |

结论必须回答：

> 它们到底是不是同一类资产？如果不是，市场为什么会把它们放在一起比较？真正应该比较的指标是什么？

## 五、输出格式

```markdown
# [行业/主题]穿透分析：到底谁真受益

## 0. 一句话结论
- 这个行业/主题到底在交易什么
- 当前处于预期阶段、订单阶段，还是业绩兑现阶段
- 最核心标的和最大风险

## 1. 先把行业讲明白
- 这个东西是什么
- 解决什么痛点
- 谁付钱，钱从哪里来
- 怎么传导到收入和利润

## 2. 卖方观点摘要与问题
- 卖方怎么看
- 证据是什么
- 哪些地方可能没讲清楚

## 3. 为什么现在发生变化
- A变化 → B客户行为 → C订单 → D业绩

## 4. 政策、产业、资本开支是否真的推动
- 预期还是订单
- 订单还是利润

## 5. 产业链分层：哪个环节最赚钱

## 6. 核心公司 vs 概念公司
- 分层标准
- 标的排序
- 每家公司受益路径

## 7. 数据验证
- 收入、订单、毛利率、费用率、现金流

## 8. 估值与price-in
- 当前市场反映了什么
- 预期差在哪里
- 什么数据会证伪

## 9. 跟踪指标和结论
- 未来1个月看什么
- 未来1个季度看什么
- 哪些信号说明逻辑增强/减弱
```

---

## 六、禁止事项

1. 禁止把卖方研报摘要当穿透分析。
2. 禁止堆政策文件但不解释订单和利润传导。
3. 禁止只列股票池，不讲受益路径。
4. 禁止把“概念相关”写成“核心受益”。
5. 禁止只比较PE/PS，不解释业务差异。
6. 禁止用海外高估值直接推导A股估值。
7. 禁止写“长期空间广阔”但不给验证指标。
8. 禁止用行业术语替代商业解释。
