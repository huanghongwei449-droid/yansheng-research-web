# 持仓诊断 V2：交易决策版

## 一、定位

本 skill 只解决一个问题：**这个持仓现在还该不该拿，什么条件下加仓，什么条件下减仓。**

它不是行业百科，也不是公司深度研究。行业背景和公司基本面只写到足以支撑持仓决策为止。

必须按买方持仓思维输出：

> 我当初/市场为什么买它 → 现在这个逻辑有没有变 → 下跌或回调伤没伤核心逻辑 → 当前位置市场已经 price-in 了什么 → 接下来用哪些指标验证 → 对应什么操作。

---

## 二、最高优先级原则

### 1. 先做“白话翻译层”

假设读者有金融基础，但没有该行业从业经验。

任何行业术语、产品术语、产业趋势，必须先翻译成商业语言：

| 必须解释 | 要求 |
|---|---|
| 这个东西是什么 | 用一句普通商业语言解释，不允许只堆术语 |
| 谁买 | 政府、金融、运营商、互联网、制造业、个人消费者等 |
| 为什么买 | 降本、提效、合规、安全、国产替代、AI需求、价格优势等 |
| 钱从哪来 | IT预算、安全预算、营销预算、资本开支、运维预算、财政预算等 |
| 怎么变成公司收入 | 一次性项目、订阅、设备销售、服务费、分成、维护费等 |
| 怎么变成利润 | 毛利率、费用率、规模效应、价格战、产品结构等 |

禁止只写“受益于AI、信创、国产替代、产业升级、景气度提升”。必须写成：

> A发生变化 → B客户行为变化 → C订单/价格/毛利变化 → D公司收入和利润变化 → E股价交易什么预期。

### 2. 持仓诊断必须比公司深度更“短、更硬、更能操作”

不要重复完整公司介绍。每一段都要回答：**这对当前持仓有什么影响？**

### 3. 证据必须分级

| 证据等级 | 类型 | 使用方式 |
|---|---|---|
| 强证据 | 财报、公告、交易所文件、招股书、定期报告 | 可以作为判断核心依据 |
| 中强证据 | IDC/Gartner/产业数据、官方政策、客户招标、订单披露 | 可以验证产业趋势 |
| 预期证据 | 券商研报、机构目标价、一致预期 | 只能说明市场在期待什么 |
| 弱证据 | 调研传闻、雪球纪要、产业链口径、专家访谈 | 只能作为线索，不能单独下结论 |
| 叙事参考 | 海外对标、未上市公司估值、概念映射 | 只能辅助理解，不得直接拿来估值 |

输出中必须标清哪些逻辑已经验证，哪些只是预期，哪些只是叙事。

### 4. 同行对比必须解释“为什么不一样”

不允许只放 PE/PS/PB 表格。同行对比至少包括：

| 维度 | 要求 |
|---|---|
| 业务本质 | 是卖产品、卖服务、卖流量、卖资源、卖软件、卖设备，还是项目制？ |
| 客户结构 | 谁付钱？客户预算是否同源？ |
| 收入质量 | 一次性、周期性、订阅型、项目型、现金牛型？ |
| 毛利率/费用率 | 为什么高，为什么低，是否可持续？ |
| 核心变量 | 这家公司股价主要看什么？收入、利润、订单、价格、现金、政策、并购？ |
| 风险来源 | 价格战、需求下滑、费用失控、毛利下滑、资本开支变化、监管等 |
| 市场交易逻辑 | 市场到底是在买成长、买修复、买红利、买资产、买主题，还是买困境反转？ |

结论必须说明：**它们是不是同一类资产，能不能直接对标。**

---

## 三、数据源清单

必须尽量扫过，但不为了完整而堆砌。只保留影响持仓决策的信息。

| 信息源 | 看什么 |
|---|---|
| 公司公告/财报 | 收入、利润、毛利率、费用率、现金流、存货、应收、合同负债、分红、并购、减持 |
| 券商研报/一致预期 | 市场推荐逻辑、目标价变化、盈利预测变化、叙事演变 |
| 互动易/调研纪要 | 公司对热点问题、订单、价格、客户、产品进展的回应 |
| 行业数据/政策 | 下游预算、客户资本开支、政策变化、供需变化 |
| 同行股价和估值 | 同期涨跌、估值差异、市场到底买谁卖谁 |
| 筹码和资本运作 | 实控人质押、减持、回购、解禁、股权激励、机构持仓 |

## 四、工作流程

## Phase 0：先定义持仓问题

开头必须先写一个“持仓矛盾”。格式：

> 当前持仓最大的矛盾是：市场在交易【核心预期】，但这个预期需要【关键指标】验证；如果验证成功，股价继续走【方向】，如果证伪，主要风险是【风险】。

如果用户没有提供成本、仓位、持有周期，则默认按“当前价格附近是否值得继续持有/是否适合加仓”来分析，不要反复追问。

输出：

| 项目 | 结论 |
|---|---|
| 当前市场交易的核心预期 | 例如业绩拐点、估值修复、AI重估、红利兑现、资产重估 |
| 最关键验证指标 | 1-3个，不要超过5个 |
| 当前位置状态 | 已充分反映/部分反映/尚未反映/可能过度反映 |
| 当前动作倾向 | 加仓/持有/减仓/等待 |

---

## Phase 1：还原上涨逻辑——市场为什么买它

按时间顺序拆上涨逻辑，不要只列催化。

| 时间/价格区间 | 催化事件 | 市场当时交易的预期 | 证据强度 | 是否仍成立 |
|---|---|---|---|---|

必须拆成三层：

1. **表层催化**：政策、订单、业绩、AI主题、目标价上调、资金抱团等。
2. **中层逻辑**：收入增速、利润率、估值体系、现金流、资产价值、行业景气。
3. **底层定价变量**：真正决定股价能否继续涨的1-3个变量。

最后输出：

> 这轮上涨真正买的是【底层变量】，不是简单的【表层概念】。

---

## Phase 2：还原下跌/回调原因——伤没伤核心逻辑

下跌原因必须分为三类：

| 类型 | 含义 | 持仓影响 |
|---|---|---|
| 杀估值 | 业绩没变，只是风险偏好下降或涨多了 | 通常可等验证 |
| 杀预期 | 核心假设没有证伪，但市场预期降温 | 需要降低仓位或等新证据 |
| 杀基本面 | 收入、订单、毛利率、现金流、竞争格局被证伪 | 应优先减仓 |

输出表：

| 下跌原因 | 证据 | 伤害哪个上涨逻辑 | 权重 | 是否可逆 | 结论 |
|---|---|---|---|---|---|

禁止把所有回调都解释成“情绪影响”。必须判断是否伤到核心变量。

---

## Phase 3：判断多空逻辑成立状态

对上涨逻辑和下跌逻辑分别打标签：

| 逻辑 | 当前状态 | 证据 | 下一步验证 | 对持仓影响 |
|---|---|---|---|---|
| 上涨逻辑1 | 已验证/验证中/待验证/已证伪 | | | |
| 上涨逻辑2 | 已验证/验证中/待验证/已证伪 | | | |
| 风险逻辑1 | 已解除/已消化/仍在/正在扩大 | | | |

必须区分：

- **已经验证**：财报/订单/价格/毛利/现金流已体现。
- **验证中**：已有初步数据，但还需要1-2个季度确认。
- **待验证**：只有产业叙事或券商预期，财务还没体现。
- **已证伪**：关键指标明显反向。

---

## Phase 4：当前位置产业检验

只检验会影响持仓动作的四件事：

### 1. 主业是否还在改善

看收入增速、订单、合同负债、毛利率、费用率、现金流。不要只看净利润。

### 2. 产业趋势是否还在推进

看客户预算、政策、招标、龙头资本开支、价格变化。

### 3. 同行是否在验证同一个方向

如果同行也涨/业绩也改善，说明行业逻辑更强；如果只有公司单独涨，要警惕个股叙事。

### 4. 估值是否已经提前透支

必须回答：

> 当前价格隐含了什么业绩/增长/利润率假设？这个假设需要多快兑现？

输出：

| 检验维度 | 当前状态 | 对持仓的含义 |
|---|---|---|
| 主业 | 改善/持平/恶化 | |
| 产业 | 加速/稳定/放缓 | |
| 同行 | 共振/分化/背离 | |
| 估值 | 便宜/合理/偏贵/透支 | |

---

## Phase 5：情景决策——给出操作而不是空泛结论

必须输出“三情景 + 触发条件 + 操作”。

| 情景 | 概率 | 触发条件 | 预期表现 | 操作 |
|---|---:|---|---|---|
| 乐观 | | 哪些数据出现才算乐观 | | 加仓/继续持有 |
| 中性 | | 哪些数据说明只是一般兑现 | | 持有/不加仓 |
| 悲观 | | 哪些数据说明核心逻辑证伪 | | 减仓/退出 |

### 交易驾驶舱

最后必须单独输出一张“交易驾驶舱”：

| 问题 | 回答 |
|---|---|
| 现在市场在交易什么？ | |
| 已经 price-in 什么？ | |
| 还没有 price-in 什么？ | |
| 最大预期差在哪里？ | |
| 未来1个月看什么？ | |
| 未来1个季度看什么？ | |
| 加仓条件 | |
| 持有条件 | |
| 减仓条件 | |
| 最重要的一句话 | |

---

## 五、输出格式

```markdown
# [公司]持仓诊断：现在该怎么处理

## 0. 一句话持仓矛盾

## 1. 先把公司/行业讲明白
- 这家公司到底卖什么
- 谁买，为什么买
- 钱从哪来，如何变成收入和利润

## 2. 市场为什么买它
- 上涨逻辑时间线
- 真正的底层定价变量

## 3. 为什么回调/下跌
- 杀估值、杀预期、杀基本面
- 是否伤害核心逻辑

## 4. 多空逻辑现在分别到哪一步
- 已验证
- 验证中
- 待验证
- 已证伪

## 5. 同行对比：它到底和谁是一类资产
- 业务本质对比
- 核心变量对比
- 估值差异原因

## 6. 当前价格隐含了什么预期
- 当前市值/估值在赌什么
- 需要什么业绩兑现

## 7. 情景决策
- 乐观/中性/悲观
- 触发条件
- 对应动作

## 8. 交易驾驶舱
```

## 六、禁止事项

1. 禁止写成行业百科。
2. 禁止只堆券商观点和目标价。
3. 禁止只说“估值高/估值低”，必须解释估值隐含的业绩假设。
4. 禁止把海外公司高估值直接套到A股公司。
5. 禁止只给“继续观察”这种没有触发条件的结论。
6. 禁止为了完整而写无关信息，例如与当前交易逻辑无关的宏大政策背景。
7. 禁止把“概念相关”写成“核心受益”。必须说明收入和利润传导路径。
